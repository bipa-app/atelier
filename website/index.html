atelier

Versioned workspaces for humans and AI agents.

GitHub crates.io docs.rs

atelier answers "what is a workspace in the age of agents": a named, versioned body of work content - code, spreadsheets, contracts, docs - with its own history, journal, profile, and policy, served to humans and agents through the same contracts.

The model

Everything is versionedNo unversioned state; every edit becomes a snapshot. Jujutsu's model is the engine, git is the boundary - every workspace is a real git repo.
Documents diff like codeOne diff library, a fidelity ladder (binary → projected text → rich), format support shipped as packages. First package: docx → markdown.
Actions are recordedHistory records content states; the journal records acts and intent - who, in which session, on whose instruction, with what approval.
Agents are first-classSessions, working copies, leases, landing, and a manifest, exposed over MCP and the CLI.

Quickstart

# the SDK
cargo add atelier-sdk

# the CLI
atelier init && atelier attach ./contracts
atelier diff        # fidelity-ladder diff: docx reads as markdown
atelier journal     # who did what, on whose instruction
atelier serve --mcp-stdio  # the agent surface
